### ID del requisito
RF-04

### Descripción
Registrar entradas, salidas y ajustes de inventario con motivo, actualizando el stock.

### Prioridad
Alta

### Fuente
ILA-004-1, ILA-020-1, ILA-020-2 (Catálogo de Requisitos v2.0.0)

### Rol / Proceso
Almacenero, Administrador / P2 Control de inventario

### Criterio de aceptación (Dado / Cuando / Entonces)
- Dado un producto con stock 10, cuando el almacenero registra una entrada de 5 con motivo "producción terminada", entonces el stock queda en 15 y el kardex muestra un movimiento INPUT de 5 con ese motivo.
- Dado un producto con stock 3, cuando el almacenero registra una salida de 4, entonces el sistema rechaza la salida y el stock sigue en 3.
- Dado un usuario con rol Almacenero, cuando intenta registrar un ajuste por merma, entonces recibe 403 (el ajuste es solo del Administrador).

### Pruebas vinculadas
PU-13, PU-14 (InventarioService); CP-06 (Selenium, kardex)

### Estado en el código (análisis)
Parcial. Existen `PUT /product-variants/{id}/stock/add` y `/stock/subtract` y `StockMovement` (INPUT/OUTPUT con motivo). Falta el tipo AJUSTE/merma restringido al Administrador.

### Versión de la ERS
v1.1
